机器人崽崽使用教程

注意

  • 崽崽不是 AI，特别笨，必须输入正确指令才能识别，不要自己乱试
  • 想了解所有功能指令，优先输入 #菜单/帮助 查看
  • 原神功能指令前加 #，星铁加 *，绝区零加 %，具体以菜单为准
使用崽崽必学：ck 绑定

使用原神、星铁、绝区零等米游社功能前，需要扫码绑定米游社 ck 信息

  • 输入 #扫码登录 后快速保存二维码，打开米游社扫码即可，绑定后记得 #刷新ck
  • ck 可能会过期，失效后输入 #刷新ck 或重新扫码
  • 输入 #删除ck 解除米游社绑定
米游社游戏签到

进行 ck 绑定后，可以进行原神、星铁、崩坏 3、崩坏 2、未定事件簿、绝区零签到，领取游戏内奖励

  • 绑定 ck 后，输入 #签到 自动进行原神、星铁、绝区零签到
  • 默认签到原神、星铁、绝区零；崩坏三签到需先输入 #开启崩坏3签到，之后说 #签到 会自动签到崩坏 3
  • 输入 #未定事件簿/崩坏2签到 进行这几个游戏的签到
  • 输入 #mys全部签到 进行米游社所有游戏社区签到，领取米币奖励
体力查询
  • 输入 #体力 实时查看原神、星铁体力、派遣、每日委托等情况
  • 输入 #开启/关闭体力推送 控制机器人是否在体力快满时进行艾特推送
uid 管理

可以绑定多个 uid

  • 输入 #uid 查看绑定的所有 uid
  • 输入 #uid + 序号，调整 uid
  • 输入 #删除uid + 序号，删除不用的 uid；扫码登录绑定的 uid 不可删除
  • 输入 #原神/星铁/绝区零禁用uid100000000，签到和查看体力就不会显示了
原神抽卡记录、充值记录查询

崽崽可以自动更新原神抽卡记录，比微信小程序好用

  • 输入 #记录帮助 查看教学
  • 输入 #更新抽卡记录 更新最近 6 个月抽卡记录（和游戏内一样有 1 小时左右延迟）
  • 输入 #更新小助手抽卡记录 自动同步微信小程序提瓦特小助手的抽卡记录
  • 输入 #全部记录 查看全部卡池记录，输入 #角色/武器/常驻记录 查看单卡池记录
  • 输入 #刷新充值记录，耐心等待几分钟后输入 #充值统计 查看充值记录
原神、星铁角色面板、群内排行

崽崽可以计算角色面板和伤害，可以模拟更换命座及武器，还可以看群排行和群友 pvp

  • 输入 #面板帮助 查看具体指令
  • 输入 #极限胡桃 查看角色极限面板
  • 星铁面板指令请换成 *，如 *希儿面板、*克拉拉排行
查询出现验证码怎么办：设备绑定

米游社最近频繁跳验证码，绑定设备即可大概率解决

  • 安卓用户下载设备信息小程序：下载设备信息 apk
  • 下载小程序，复制消息发在群里即可绑定，两种绑定口令有区别，一定要看图
  • 绑定原神、星铁与绝区零请参考对应教学图（图见文档）
其他功能指令菜单

这些功能的指令更复杂，可以看看群友怎么用，有样学样就好了

  • 输入 #菜单/帮助 查看功能指令，想了解如何使用请优先参考此菜单
  • 原神功能一般需要在指令前加 #
  • 星铁功能一般需要在前面加 *
  • 绝区零功能一般需要在前面加 %
  • 具体以菜单为准
  • 由于各功能来自于网上不同的作者，某些功能出问题是正常现象，敬请谅解
