常用功能详解

使用崽崽必学：ck 绑定

使用原神、星铁、绝区零等米游社功能前，需要扫码绑定米游社 ck 信息。

  • ❤️ 输入 #扫码登录 后快速保存二维码，打开米游社扫码即可，绑定后记得 #刷新ck
  • ❤️ ck 可能会过期，失效后输入 #刷新ck 或重新扫码
  • ❤️ 输入 #删除ck 解除米游社绑定
使用示例
第一次绑定：#扫码登录 → 保存二维码 → 米游社扫码 → 完成后再发 #刷新ck
ck 过期了：直接发 #刷新ck，或重新 #扫码登录
要解绑：发 #删除ck
米游社游戏签到

进行 ck 绑定后，可以进行原神、星铁、崩坏 3、崩坏 2、未定事件簿、绝区零签到，领取游戏内奖励。

  • ❤️ 绑定 ck 后，输入 #签到 自动进行原神、星铁、崩坏 3、绝区零签到
  • ❤️ 默认签到原神、星铁、绝区零；崩坏三签到需先在群里输入 #开启崩坏3签到，之后说 #签到 会自动签到崩坏 3
  • ❤️ 输入 #未定事件簿/崩坏2签到 进行这几个游戏的签到
  • ❤️ 输入 #mys全部签到 进行米游社所有游戏社区签到，领取米币奖励
使用示例
日常签到：#签到（默认自动签原神、星铁、绝区零）
开崩坏三：先发 #开启崩坏3签到，之后 #签到 就会带上崩坏 3
其他游戏：#未定事件簿/崩坏2签到
社区全签：#mys全部签到（还能领米币）
体力查询
  • ❤️ 输入 #体力 实时查看原神、星铁体力、派遣、每日委托等情况
  • ❤️ 输入 #开启/关闭体力推送 控制机器人是否在体力快满时进行艾特推送
使用示例
随时查体力：#体力
想被提醒：#开启体力推送
嫌吵就关：#关闭体力推送
uid 管理

可以绑定多个 uid。

  • ❤️ 输入 #uid 查看绑定的所有 uid
  • ❤️ 输入 #uid + 序号，调整 uid
  • ❤️ 输入 #删除uid + 序号，删除不用的 uid；扫码登录绑定的 uid 不可删除
  • ❤️ 输入 #原神/星铁/绝区零禁用uid100000000，签到和查看体力就不会显示了
使用示例
查看全部：#uid
切换到第 1 个：#uid 1
删掉第 2 个：#删除uid 2
让某个 uid 不显示：#原神禁用uid100000000
原神抽卡记录、充值记录查询

崽崽可以自动更新原神抽卡记录，比微信小程序好用！

  • ❤️ 输入 #记录帮助 查看教学
  • ❤️ 输入 #更新抽卡记录 即可更新最近 6 个月抽卡记录（和游戏内一样有 1 小时左右延迟）
  • ❤️ 输入 #更新小助手抽卡记录 即可自动同步微信小程序提瓦特小助手的抽卡记录，方便快捷
  • ❤️ 输入 #全部记录 查看全部卡池记录，输入 #角色/武器/常驻记录 查看单卡池记录
  • ❤️ 输入 #刷新充值记录，耐心等待几分钟后输入 #充值统计 查看自己的充值记录
使用示例
先看教学：#记录帮助
更新抽卡：#更新抽卡记录（同步微信小程序就用 #更新小助手抽卡记录）
看全部卡池：#全部记录；只看单池：#角色记录 / #武器记录 / #常驻记录
查充值：先 #刷新充值记录，等几分钟再 #充值统计
原神、星铁角色面板、群内排行

其实看群友怎么用也就懂了，崽崽可以计算角色面板和伤害，可以模拟更换命座及武器，还可以看群排行和群友 pvp。

  • ❤️ 输入 #面板帮助 查看具体指令
  • ❤️ 输入 #极限胡桃 查看角色极限面板
  • ❤️ 星铁面板指令请换成 *，如 *希儿面板、*克拉拉排行
使用示例
原神面板：#极限胡桃（换成自己想看的角色名字即可）
原神排行：#胡桃排行
星铁面板：*希儿面板；星铁排行：*克拉拉排行
更多指令：#面板帮助
查询出现验证码怎么办：设备绑定

米游社最近频繁跳验证码，绑定设备即可大概率解决。

  • ❤️ 安卓用户点击链接下载设备信息小程序：下载设备信息 apk
  • ❤️ 下载小程序，复制消息发在群里即可绑定，两种绑定口令有区别，一定要看教学图
  • ❤️ 绑定原神、星铁教学图（图片占位）
  • ❤️ 绑定绝区零教学图（图片占位）
使用示例
先下载设备信息小程序：点此下载 apk
运行小程序复制设备消息，发到群里即可绑定
注意：原神、星铁与绝区零的绑定口令不同，务必看对应教学图
